# Till — launch film

A 30-second, 16:9 launch cut for X. One panel morphs through the paid-call order, the
ledger and the payout route; nothing is cut. Readable with the sound off, scored and
sound-designed for 120 BPM.

**File:** `till-launch.mp4` — 1920×1080, 30 fps, 900 frames, H.264 High + AAC 48 kHz
stereo, 30.000 s, 2.2 MB, `sha256 f840859119d9e7350f022d0f5d56a1d618bfd34787b10a5f828f268cf7d43a2c`.
`storyboard.jpg` is one frame per second (5×6); `stills/` holds six key frames.

## The film

| Time | Beat | What is on screen |
|---|---|---|
| 0.0–4.0 | Logo | Four squares assemble into the Till mark; the wordmark tracks in. |
| 4.0–9.0 | The paywall | The panel becomes a terminal: `GET /r/demo` → `402`, the six signed terms, then the agent's cursor pays and the line reads `verify → guards → upstream → settle`. |
| 9.0–14.0 | The order | The panel widens into four columns. Verify, Guards, Upstream and Settle light on consecutive beats; the caption lands on the rule: nothing settles before the upstream answers. |
| 14.0–19.0 | The ledger | A hairline ledger table fills row by row while the session total rolls to 1.260000 USDC; the footer names append-only, the trigger and `bigint`. |
| 19.0–24.0 | Payout and reconcile | Paid in USDC on NEAR → NEAR Intents → USDC on Ethereum, then the six rules and `payment_in.tx = swap.deposit tx = payout_out.tx`. |
| 24.0–30.0 | End card | The mark and TILL return with the line “Charge agents by the request. Prove every payout.” and `Built at NEAR Hackathon 2026`. |

## Real vs invented

- **The flow is real product behavior:** the paid-call order, settle-only-on-2xx, the
  append-only ledger, six reconcile rules and tx-hash matching are the shipped rules.
- **The numbers are a demo trace, not a live sale.** The addresses, hashes and the
  1.260000 USDC total are illustrative, matching the seed/demo data shape. No wallet
  paid for this film and no mainnet transaction happened.
- **The payout leg is labelled:** the end card says `testnet trace · payout provider:
  mock`. That is the honest state of the build, not a claim of live cross-chain money.
- No customer logos, no real people and no licensed footage are used. Every pixel and
  every sound is generated by the two source files here.

## Director's decisions

1. **One shape, never cut.** The panel's rectangle is interpolated between keyframes;
   content swaps with a 5 px blur, and a scene-change scan (`ffmpeg scene > 0.30`)
   finds no cut in the finished file.
2. **Till's own design system, not a template.** `#070809` ink, `#c9ff57` acid,
   hairline `#25282d`, mono for every number, square edges, zero gradients.
3. **The cursor is the agent.** It appears once, in the terminal, and pays; the film
   does not need a second cursor to explain a table.
4. **Music first.** The score is written to a 120 BPM grid, and the scene hits, step
   ticks and clicks land on the same numbers the picture uses.
5. **Sound off must work.** Every claim is on screen as text; the soundtrack adds
   energy but carries no information.
6. **30 fps, not 60.** Two subframes per frame are averaged (`tmix`) into a 30 fps
   master with motion blur; this keeps the file postable on X and the motion soft.

## Rebuild

Needs Node 22, Python 3 (stdlib only), ffmpeg and Google Chrome; no npm dependency.

```sh
cd docs/video/launch-film
python3 score.py                 # writes score.wav
node render.mjs                  # writes silent.mp4 through headless Chrome + ffmpeg
ffmpeg -y -i silent.mp4 -i score.wav -c:v copy -c:a aac -b:a 192k -shortest \
  -movflags +faststart till-launch.mp4
ffmpeg -y -i till-launch.mp4 -vf "fps=1,scale=384:216,tile=5x6" -frames:v 1 storyboard.jpg
```

`index.html` is a pure function of time: `window.seek(t)` sets every style and string,
so any frame can be reproduced from `index.html#t=12.5`.

## Caveats

- **Audio was measured, not heard.** `volumedetect` reports mean −22.7 dB and max
  −1.9 dB, and the cue times are the same constants the picture uses; nobody listened
  to the mix in this session, so the balance is unverified by ear.
- **No tailnet or public URL was served.** The file is in this folder; upload it with
  the post.
- **This is the launch film, not the demo evidence.** The PRD §8 demo recording is
  `docs/video/first-cut.mp4` (H1); this cut is marketing and says so on the end card.
- **No voiceover and no captions track.** The cut is designed to be read, not heard.
